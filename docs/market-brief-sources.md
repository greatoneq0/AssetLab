- [서울외국환중개 서비스 안내](https://www.smbs.biz/InfoSV/SV_IntroMobile.jsp): 윈터타임에는 07:00. 매일 시장이 닫히는 것이 아니라 일일 가격 집계 경계라는 점에 유의합니다.
- [KB국민은행 공식 안내](https://kbthink.com/fx/24-hour-forex-market.html): 일일 집계는 06:00~익일 06:00(미국 서머타임)이며, 주말·1월 1일을 제외한 한국 공휴일에도 거래합니다. 15:30 종가와 매매기준율은 별개입니다. 거래일은 이 구간이 시작한 날짜, 마감일시는 다음 달력 날짜로 표시합니다. FX에 XKRX 휴장일을 적용하지 않습니다.
- [실제 야간 마감 보도 예](https://stock.mk.co.kr/news/view/1116606): 2026-07-07 06:00 서울 외환시장 마감 1,530.0원. 귀속 거래일은 2026-07-06입니다. 15:30 종가와 비교한 기사 등락폭을 야간 종가 대비 등락률로 오인하지 않도록 FX 등락률은 표시하지 않습니다.

구현은 공개 RSS로 발견한 언론사 **본문**에서 같은 날의 `N일 오전 6시/7시 ... 서울 외환시장 ... 원·달러 환율 ... X원에 거래를 마감`처럼 날짜·시각·가격과 실제 완료 마감이 한 절에 명시된 문장만 받습니다. 주간/야간의 여러 마감 가격이 한 문장에 섞이거나 전망·예상 표현이면 거부합니다. 기사 발행일, 예상 마감시각, 현재시각을 대조합니다. 숫자 충돌, 오래된 보도, 주간/역외 시세, 제목만 있는 보도는 채택하지 않습니다. 현재의 제도 시작 이전 및 연말 특별 마감은 별도 검증 없이는 조회 불가입니다.

[서울외국환중개 표](https://www.smbs.biz/ExRate/StdExRate.jsp)에 `06:00 종가`가 검색 색인에 보이지만 원문 조회가 502/프록시 403으로 실패했습니다. 표의 날짜 열이 거래일인지 공시일인지 검증하지 못했으므로 임의 파서를 배포하지 않았습니다. 기사 본문을 얻지 못하거나 엄격한 문장 조건이 맞지 않으면 **서울 야간 종가 확인 불가**로 표시합니다. Yahoo KRW=X, 15:30 가격, MAR, NDF로 폴백하지 않습니다. 공개 RSS의 보도 범위 때문에 매일 값이 확보된다는 보장은 없습니다.

## 뉴스

- [매일경제 공식 RSS 목록](https://www.mk.co.kr/rss)의 증권·경제·국제 피드.
- [한국경제 증권 RSS](https://www.hankyung.com/feed/finance).
- 뉴스 API 키, 유료 모델, 신규 인증 설정 없이 RSS와 기사 본문/설명을 수집합니다.
- 실제 표시하는 종목별 시세와 동일한 사건 날짜·상승/하락 방향·완료된 마감 표현을 한 문장에서 검증한 뒤 원인 문장을 짧게 발췌합니다. 시세를 얻지 못한 종목, 날짜가 없는 문장, 과거 회고·미래 전망, 여러 종목이나 사건이 섞인 문장은 채택하지 않습니다. 생성형 원인 추론이나 서로 다른 문장 조합을 하지 않습니다. 이는 여러 기사를 종합한 해설이 아닌 **출처가 붙은 발췌 요약**입니다.
- 최근 72시간의 기사 중 해당 종목의 실제 시세 기준일과 현지 시간대에 맞는 기사를 사용합니다. 비한국 시장에 미국 거래일을 일괄 적용하지 않습니다. 기사 3개 제한은 사건 검증을 통과한 후 시장별로 적용합니다. 제목만 반복한 RSS 설명은 근거로 인정하지 않습니다. 발행시각은 KST로 표시하며 가격 기준일과 구분합니다. 원인 문장이 없으면 미확인으로 표시합니다.
- HTML/XML 변경, 차단, RSS 미게재, 엄격한 길이/날짜 조건 때문에 일부 시장의 이유가 빠질 수 있습니다. 링크·발췌를 중간에서 자르지 않고 메시지 길이 제한을 지킵니다.

## 검증

`python -m pytest -q`는 저장된/합성 응답을 사용하며 실제 텔레그램을 호출하지 않습니다. 기사 파서는 공개된 실제 마감 보도 문장도 테스트합니다. 본 작업 환경의 외부 사이트 직접 연결은 프록시 403으로 차단되어 **실제 최신 FX/RSS 수집 성공은 검증되지 않았습니다**. `python tools/market_brief.py --dry-run`은 발송 없이 실제 조회 결과 또는 조회 불가를 출력합니다. 어떤 secret이나 지속 인증 설정도 추가하지 않습니다.

## 메시지 예시

아래는 2026-10-15에 `--dry-run`으로 실제 출력한 내용의 발췌입니다. 네트워크 접근 실패를 숨기거나 시험 가격을 실제 값으로 표시하지 않습니다.

```text
🌐 기준일 2026-10-14 · 각 시장 현지 종가 (예외는 별도 표기)

• 코스닥: 확정 종가 조회 실패

  거래일 2026-10-14 / 마감 2026-10-15 06:00 KST
  해당 시각·가격이 명시된 마감 보도 미확보

📰 시장 움직임의 배경 — 기사 발췌 (발행시각 KST)
• 미국: 확인 가능한 원인 기사 없음
```

성공 경로는 위의 실제 7월 7일 마감 기사 문장으로 테스트했습니다. 해당 날짜의 입력으로 렌더링하면 다음과 같이 표시됩니다(오늘 시세가 아닌 과거 기사 재현).

```text
💱 원/달러: 1,530.00원 — 서울 야간 종가(일일 경계)
  거래일 2026-07-06 / 마감 2026-07-07 06:00 KST
  매일경제 마감 보도: https://stock.mk.co.kr/news/view/1116606
```

원인 기사 성공 경로는 합성 fixture로 발췌·발행시각·링크 일치, 원인 미기재 거부, 현재 장중 기사를 전일 한국장 이유로 사용하지 않는 것을 검증합니다. 최신 원인 기사 성공 예시를 이 환경에서 검증한 것으로 제시하지 않습니다.
